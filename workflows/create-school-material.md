# Create School Material

## Cel
Przygotować materiał szkolny zgodnie z zatwierdzonymi zasadami.

## Kroki
1. Pobierz źródła z `knowledge-base/`.
2. Sprawdź zakres materiału.
3. Napisz treść roboczą.
4. Zweryfikuj poprawność.
5. Zapisz wersję zatwierdzoną.

## Checklista
- [ ] Dane szkoły są potwierdzone.
- [ ] Treść jest zgodna z programem.
- [ ] Format jest gotowy do użycia.
