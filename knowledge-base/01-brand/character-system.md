## Purpose

Dokument określa system postaci marki eKanada.

## Scope

Dokument obejmuje spójny świat bohaterów oraz ich rolę w ekosystemie marki.

## Core Content

System postaci marki tworzy spójny świat bohaterów, którzy wspierają komunikację, edukację i budowanie relacji w ekosystemie eKanada. Nie jest zbiorem niezależnych maskotek ani zamkniętym katalogiem postaci. Każdy bohater posiada uzasadnioną rolę i pozostaje częścią wspólnej struktury wynikającej z tożsamości marki. System ma pierwszeństwo przed rozwojem pojedynczej postaci.

## Usage Guidance

Stosuj system postaci jako wspólną strukturę, a nie katalog oddzielnych bohaterów.
