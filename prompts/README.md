# Prompts

Folder przechowuje prompty robocze dla procesu tworzenia materiałów.

## Podfoldery
- `images/` - prompty do obrazów i edycji grafiki.
- `marketing/` - prompty do treści marketingowych.
- `school/` - prompty do materiałów szkolnych.
- `review/` - prompty do kontroli i oceny materiałów.
- `automation/` - prompty wspierające przyszłe automatyzacje.
